# SA2.2 TEST AUTH NOTE

이 브랜치는 운영본과 분리된 사용성 테스트 복사본이다.

사용자 흐름:
1. 이름 선택
2. 4자리 PIN 설정
3. 자동 로그인
4. 세션 만료 시 PIN 재인증

주의:
- 사용자에게 등록키/Google OAuth를 요구하지 않는다.
- 현재 테스트본의 첫 등록은 허용 사용자 목록 선택만으로 가능하므로 운영용 최종 보안 모델이 아니다.
- 운영 전에는 관리자 기기 승인 또는 1회용 초대 승인 절차를 서버 측에 추가해야 한다.
- 기존 owner/writer/reader 권한과 Audit actor는 유지한다.
